# Source tiers for seed runs (a fragment)

The seed-run variant of source_tiers.md: the same table, without the sentence on
the episode's tier (a seed run has no episode). Keep the two files in step.
---
| Tier | Sources |
| --- | --- |
| 1 | Primary texts (Project Gutenberg, Perseus, publisher editions) |
| 2 | Academic references: Stanford Encyclopedia of Philosophy, Internet Encyclopedia of Philosophy, university presses, peer-reviewed papers |
| 3 | Serious magazines, published lectures, interviews with the author |
| 4 | Everything else |

Any claim a segment's argument rests on needs tier 1 or 2. Tier 4 may be used for color only, never for a factual claim.
