# Source tiers (a fragment, not a prompt of its own)

Inserted as {{source_tiers}} into the ledger, research, ledger update, brief,
draft and edit prompts, so the tier table is defined in one place. From the
ledger add-on (docs/ledger-research-addon.md, "Source tiers").
---
| Tier | Sources |
| --- | --- |
| 1 | Primary texts (Project Gutenberg, Perseus, publisher editions) |
| 2 | Academic references: Stanford Encyclopedia of Philosophy, Internet Encyclopedia of Philosophy, university presses, peer-reviewed papers |
| 3 | Serious magazines, published lectures, interviews with the author |
| 4 | Everything else |

Any claim a segment's argument rests on needs tier 1 or 2. Tier 4 may be used for color only, never for a factual claim. Something taken from the podcast episode itself is tier "episode": it is what the chapter starts from, not evidence for it.
