# Names a guide may choose from (not sent whole)

land on the same few names, so the server hands the guide a small random draw
from this list (config.yaml guide.name_draw), and it picks from those or one
the conversation suggests. One name per line below the line; add freely. Names
models over-pick (Nova, Sage, Aria, Echo, Luna, Kai, Orion, Atlas) are left out
on purpose.
